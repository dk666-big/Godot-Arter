# Godot-Arter 网页联动 · 浏览器扩展安装说明

把 **ChatGPT / Gemini 网页版**变成 Godot-Arter 的免费生图后端：

- 工坊里点「打开网页版」或选「🌐 网页版」供应商生成 → 扩展把提示词**自动填入**网页对话框（**只填入，不自动发送**，检查后自己点发送）
- 网页生成图片后，点图片右上角「💾 Godot-Arter」→ 图片自动保存到项目 `assets/generated/`，元数据（提示词/来源/时间）记录到 `data/generated_assets.json`
- 工坊页面（经 `node server.mjs` 访问时）每 8 秒自动检查收件箱，把新图**导入素材库**

## 安装（Chrome / Edge 通用，MV3）

1. 先启动本地服务：在项目根目录 `node server.mjs`（或双击 `启动游戏工坊.bat`）
2. Chrome 打开 `chrome://extensions` ／ Edge 打开 `edge://extensions`
3. 右上角打开「**开发者模式**」
4. 点「**加载已解压的扩展程序**」，选择本目录（`extension/`）
5. （可选）点扩展图标 → 「🔍 测试连接」确认联动服务在线

## 使用

1. 打开 `http://127.0.0.1:3080/game-art-studio`
2. 任意工坊填好提示词 → 供应商选「🌐 ChatGPT 网页版」或「🌐 Gemini 网页版」→ 点生成
   （或在「API 预设 → 免费网页版入口」直接点「打开网页版」按钮）
3. 切到打开的 ChatGPT/Gemini 标签页：提示词已被自动填入，检查后手动点发送
4. 生成完成后，把鼠标移到图片上 → 点「💾 Godot-Arter」→ 显示 ✅ 文件名即保存成功
5. 回到工坊：右下角弹出「📥 已导入 N 张」，素材出现在「素材总管 → 素材库」

## 设置

点扩展图标可修改：

- **联动服务地址**：默认 `http://127.0.0.1:3080`（改了 server.mjs 端口时同步修改）
- **自动填入提示词**：关掉后扩展只负责保存按钮
- **保存按钮**：关掉后不再往网页注入按钮

## 常见问题

- **提示词没自动填入？** 网页改版可能导致输入框选择器失效——此时扩展会把提示词复制到剪贴板，手动粘贴即可；欢迎反馈新的选择器。
- **保存按钮没出现？** 只对 ≥200×200 且位于回复消息内的图片注入；历史消息里的旧图刷新页面后会出现。
- **点保存报「连不上」？** 确认 `node server.mjs` 在运行、扩展弹窗里地址端口一致。
- **file:// 双击打开工坊时**：联动功能不可用（浏览器限制），请用本地服务方式。
